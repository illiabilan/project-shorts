Параметри YouTube Data API v3 Google Cloud Console
Як отримати client_secrets.json та token.json?
  1. Увійдіть у Google Cloud Console та створіть проєкт (наприклад, OpenShorts).
  2. Увімкніть API: відкрийте сторінку YouTube Data API v3 та натисніть Enable.
  3. Налаштуйте екран згоди: в OAuth consent screen оберіть External, вкажіть назву та у розділі Test users обов'язково додайте свою електронну адресу YouTube-каналу.
  4. Створіть ключ: у Credentials натисніть + Create Credentials → OAuth client ID → тип Desktop application.
  5. Завантажте отриманий файл та збережіть як credentials/client_secrets.json (або вкажіть шлях чи вставте JSON у поле).
  6. Авторизація token.json: натисніть кнопку "Перевірити підключення" нижче — у браузері відкриється вікно дозволу Google, після чого токен буде створено автоматично.
Параметри TikTok Creator / Content Posting API
Upload-Post TikTok Dev
Як підключити TikTok? (2 способи)
Спосіб 1: Через Upload-Post API (Швидко і просто)
  1. Створіть акаунт на upload-post.com.
  2. Підключіть свій TikTok-профіль через QR-код або авторизацію в кабінеті.
  3. Скопіюйте свій API Key та user_id (профіль) і вставте в блок нижче.
Спосіб 2: Офіційний TikTok Content Posting API
  1. Увійдіть у TikTok Developer Portal та зареєструйте додаток.
  2. Додайте продукт Content Posting API або Share on TikTok.
  3. Необхідні дозволи (Scopes): video.upload, video.publish.
  4. Згенеруйте Creator Access Token та вставте його нижче.

Параметри Meta Graph API (Instagram Reels)
Graph Explorer Meta Apps
Як отримати Instagram Account ID та Access Token?
⚠️ Обов'язкова вимога Meta: Ваш Instagram має бути Професійним (Business / Creator) та зв'язаним із публічною Facebook-сторінкою (Сторінка → Налаштування → Instagram).
  1. Зайдіть у Meta for Developers і створіть додаток типу Business.
  2. Відкрийте Graph API Explorer:
    • Виберіть свій додаток у списку Meta App
    • У User or Page Token оберіть свій профіль Facebook
    • Додайте дозволи: instagram_basic, instagram_content_publish, pages_show_list
    • Натисніть Generate Access Token
  3. Знайти Instagram Account ID: у полі запиту Explorer введіть:
    me/accounts?fields=id,name,instagram_business_account Натисніть Submit і скопіюйте числове значення instagram_business_account.id.
  4. Отримати 60-денний токен: відкрийте Access Token Tool, натисніть Debug → Extend Access Token. Скопійований токен дійсний 60 днів.

Потрібні дозволи: instagram_content_publish, pages_show_list
Параметри X (Twitter API v1.1 + v2) X Dev Portal
Як згенерувати 4 ключі доступу в X Developer Portal?
  1. Увійдіть у X Developer Portal (достатньо тарифу Free або Basic).
  2. Відкрийте Projects & Apps і створіть або оберіть ваш додаток.
  3. Обов'язкові налаштування прав: у вкладці Settings знайдіть User authentication settings та натисніть Set up (Edit):
    • Увімкніть перемикач OAuth 1.0a
    • У блоці App permissions вкажіть Read and write (Читати та писати)
    • Збережіть форму
  4. Відкрийте вкладку Keys and tokens:
    • У розділі Consumer Keys скопіюйте API Key та API Key Secret
    • У розділі Authentication Tokens згенеруйте Access Token and Secret (переконайтесь, що вони мають статус Read and Write)
  5. Вставте всі 4 отримані значення у поля нижче.
