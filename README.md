## 💡 Що це таке?

**Project Shorts** — це приватна, безлімітна та автономна фабрика контенту, яка працює на вашому власному комп'ютері. Вона бере будь-яке довге YouTube-відео (подкаст, інтерв'ю, стрім чи лекцію), знаходить найцікавіші моменти за допомогою ШІ, утримує спікера в кадрі 9:16, накладає динамічні субтитри, генерує стильну інтро-заставку та автоматично публікує ролики за розкладом.

**Без щомісячних підписок, без водяних знаків і без лімітів на хвилини.**

## ✨ Можливості

* 🧠 **Мультипровайдерний ШІ-аналіз**: Підтримка Google Gemini (3.6 Flash / 3.1 Flash-Lite), OpenRouter (Claude 3.5 Sonnet, Llama 3.3, DeepSeek), Fireworks AI, Anthropic Claude, OpenAI (GPT-4o) та локальної Ollama.
* ⚡ **Апаратне прискорення GPU (VA-API / NVENC)**: Рендеринг 70-секундного кліпу у Full HD 1080x1920 триває всього **~4–5 секунд** на відеокартах AMD (Radeon RX 7000/6000) та NVIDIA.
* 🎙️ **Локальний Whisper ASR**: Точне транскрибування з таймкодами для кожного слова на базі `faster-whisper` (`large-v3-turbo` / `small`) із вибором девайса (GPU ROCm/CUDA або CPU).
* 🎯 **Smart Face Tracking (MediaPipe + YOLO)**: Автоматичне стеження за активним спікером (режими *Track*, *Split-screen* для двох людей у подкасті, *Screencast*).
* 🖼️ **Freeze-Frame Hook Intro Card**: Генерація стильної вступної заставки на 1.8 с із сильним Gaussian blur першого кадру, напівпрозорим затемненням та акцентним заголовком хука. Субтитри ідеально синхронізуються без зсуву аудіо.
* 🎨 **Сучасний Material Design 3 Web Dashboard**:
  - Інтерактивна черга відео з покроковим прогресом у реальному часі.
  - Галерея змонтованих роликів із вбудованим плеєром та швидким завантаженням.
  - 3-режимний перемикач тем оформлення (Світла / Темна / Системна).
  - Повне керування всіма параметрами системи без ручного редагування `.env`.
* 📅 **Автоматичний шедулінг та автопостинг**:
  - Безпечна інтерактивна OAuth 2.0 авторизація в браузері в 1 клік.
  - Автоматичний розклад публікації в YouTube Shorts (publishAt) з інтервалом (наприклад, кожні 3 години).

## 🚀 Швидкий запуск

### Спосіб 1: Linux / macOS (в 1 команду)

1. **Клонуйте репозиторій**:
   ```bash
   git clone git@github.com:illiabilan/project-shorts.git
   cd project-shorts
   ```

2. **Запустіть скрипт початкового налаштування**:
   ```bash
   ./setup.sh
   ```
   Скрипт автоматично:
   - Встановить надшвидкий менеджер оточень `uv`;
   - Створить віртуальне оточення Python 3.11;
   - Склонує кастомізований рушій [`illiabilan/openshorts`](https://github.com/illiabilan/openshorts);
   - Встановить залежності та перевірить FFmpeg;
   - Підготує конфігураційний файл `.env`.

3. **Запустіть систему**:
   ```bash
   ./start.sh
   # або: .venv/bin/python run_all.py
   ```
   *Панель керування автоматично відкриється у браузері за адресою:* **`http://localhost:8080`**.

4. **Зупинка**:
   ```bash
   ./stop.sh
   # або натисніть Ctrl + C у терміналі
   ```

### Спосіб 2: Windows (Для звичайних користувачів, без терміналу)

1. Завантажте репозиторій у папку на комп'ютері.
2. Двічі клікніть по файлу **`Встановити_Windows.bat`** (скрипт підготує все необхідне та створить ярлик на Робочому столі).
3. Щодня запускайте програму подвійним кліком по ярлику **`Project Shorts`** на Робочому столі або файлу **`Запустити_Shorts.bat`** чи **`Запустити_Shorts_Вікно.vbs`**.
4. Докладніше простою мовою читайте у файлі [ІНСТРУКЦІЯ_ДЛЯ_КУМА.txt](ІНСТРУКЦІЯ_ДЛЯ_КУМА.txt).

## ⚙️ Налаштування

Всі налаштування зручно редагуються через вкладку **«Налаштування»** у веб-інтерфейсі або безпосередньо у файлі `.env`:

| Змінна | За замовчуванням | Опис |
| :--- | :--- | :--- |
| `LLM_PROVIDER` | `gemini` | Провайдер ШІ (`gemini`, `openrouter`, `fireworks`, `anthropic`, `openai`, `ollama`) |
| `GEMINI_API_KEY` | - | Безкоштовний ключ із [Google AI Studio](https://aistudio.google.com/) |
| `GEMINI_MODEL` | `gemini-3.6-flash` | Модель для пошуку вірусних фрагментів |
| `FFMPEG_ENCODER` | `vaapi` | Енкодер відео: `vaapi` (AMD GPU), `nvenc` (NVIDIA GPU), `x264` (CPU) |
| `WHISPER_MODEL` | `large-v3-turbo` | Розмір моделі Whisper (`large-v3-turbo`, `small`, `base`) |
| `WHISPER_DEVICE` | `cuda` | Де виконувати Whisper: `cuda` (ROCm / CUDA) або `cpu` |
| `WHISPER_COMPUTE`| `float16` | Тип обчислень (`float16` для GPU, `int8` для CPU) |
| `CLIP_MIN_SECONDS` | `20.0` | Мінімальна тривалість кліпу (сек) |
| `CLIP_MAX_SECONDS` | `180.0` | Максимальна тривалість кліпу (сек) |
| `AUTO_HOOK` | `1` | `1` — хук увімкнено, `0` — вимкнено |
| `AUTO_HOOK_MODE` | `intro` | `intro` (заставка з розмиттям) або `overlay` (плашка поверх відео) |
| `AUTO_HOOK_SECONDS` | `1.8` | Тривалість показу заставки хука (сек) |
| `AUTO_HOOK_STYLE` | `classic` | Стиль оформлення хука (`classic`, `dark`, `yellow`, `red`, `outline`) |
| `AUTO_POST` | `false` | Автоматична публікація шортсів у YouTube |
| `AUTO_POST_INTERVAL_HOURS`| `3.0` | Інтервал публікації нових роликів у годинах |

## ⚡ Апаратне прискорення

Найефективніший сетап для роботи — **гібридний**:
* **Аналіз вірусності (LLM)**: виконує хмарна модель **Gemini 3.6 Flash** (величезне вікно контексту в 1 млн токенів аналізує годину подкасту за 2–3 секунди, а коштує менше 0.001$).
* **Транскрибування та Рендеринг**: виконуються локально на GPU:
  - **AMD Radeon (наприклад, RX 7800 XT / 6700 XT)**: увімкніть `FFMPEG_ENCODER=vaapi`. Відеокарта зшиває 70-секундний ролик із фільтрами всього за **4.8 секунди**!
  - **NVIDIA GeForce RTX**: увімкніть `FFMPEG_ENCODER=nvenc` та `WHISPER_DEVICE=cuda`.

## 📤 Авторизація та публікація в YouTube Shorts

1. Отримайте файл `client_secrets.json` (тип: *OAuth 2.0 Client ID, Desktop Application*) у [Google Cloud Console](https://console.cloud.google.com/).
2. Покладіть його у папку проєкту: `credentials/client_secrets.json`.
3. У веб-панелі перейдіть у вкладку акаунтів і натисніть кнопку **«Авторизувати Google»** (або запустіть `./auth_youtube.sh` у терміналі).
4. У браузері підтвердьте доступ до вашого YouTube-каналу.
5. Готово! Система генерує токен і може автоматично або вручну викладати змонтовані кліпи.
